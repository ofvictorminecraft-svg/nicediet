# NiceDiet

Prywatny dashboard treningu i diety, bez frameworków i bez bazy danych.

## Uruchomienie
Otwórz `index.html` w przeglądarce albo skopiuj pliki do katalogu Apache2. Nie jest potrzebny Node.js ani npm.

## Funkcje
- Ekran główny z podsumowaniem kalorii, białka i aktywności.
- Trening góry ciała bez sprzętu: pompki, pike push-ups, wiosłowanie plecakiem, unoszenie butelek, reverse crunch i plank.
- Zaznaczanie wykonanych serii, timer odpoczynku i historia sesji.
- Przykładowe propozycje prostych posiłków, filtry oraz dziennik jedzenia.
- Szybkie dodawanie odżywki WPC 80 Pure (60 g: ~227 kcal / 48 g białka).
- Waga, obwód pasa, wykresy postępów i cele edytowane w ustawieniach.
- Eksport i import danych JSON.
- Przechowywanie danych tylko w localStorage danej przeglądarki.

## Ważne
Przykładowe wartości posiłków i cel kaloryczny są demonstracyjne. Dostosuj je do własnych produktów oraz indywidualnego zapotrzebowania. Dziennik nie zastępuje konsultacji dietetycznej ani medycznej.

## Publikacja na Apache2
Wgraj `index.html`, `styles.css`, `app.js` i `favicon.svg` do katalogu DocumentRoot. Otwórz adres domeny.

## Rozwój
Można później dodać bazę ulubionych produktów Biedronki, własne dania, integracje, konto użytkownika i synchronizację między urządzeniami.
